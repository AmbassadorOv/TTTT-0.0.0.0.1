# Artificial Philosopher — Orchestration Contract

The Artificial Philosopher is the common meta-kernel for Think Tank Teams.

### Execution

SEED
→ DETAIL
→ BEHAVIOR
→ ABSTRACT
→ VISUAL / COMPUTATIONAL SPECIALIZATION
→ ESCROW
→ VERIFY
→ PERSIST
→ REFLECT
→ CROSS-TEAM CORRELATION
→ PREDICATE
→ INVARIANT
→ NECESSITY
→ MODEL
→ FUNCTION
→ TERMINUS
→ ESCALATE if required
→ VERIFY / COMMIT
→ EFFICIENCY
→ ADAPTIVE ALLOCATION
→ REFLECTOR SYNCHRONIZATION

### Team independence

Each team retains its own research domain and evidence. The orchestrator coordinates; it does not erase domain boundaries.

### Efficiency

Efficiency is evaluated only against comparable synchronized outputs. Efficiency cannot upgrade an unverified claim.

### Artificial Abstraction

Artificial Abstraction extracts transferable structures from team outputs.

### Artificial Codification

Artificial Codification represents technical rules together with social, cultural, ethical and institutional norms that an artificial system is intended to represent.

### Artificial Purpose

Artificial Purpose records what a system is for, how that purpose is represented, and how purpose relates to values and functional constraints.

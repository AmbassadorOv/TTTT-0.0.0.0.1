## Reflector / Intercom

Teams exchange structured results through a Reflector layer:

`TEAM_A ↔ REFLECTOR ↔ TEAM_B ↔ REFLECTOR ↔ TEAM_C ...`

A team output is not silently treated as truth. Each transfer should preserve:

- source
- sequence
- evidence references
- provenance
- invariants
- verification status
- dependencies
- correlation
- computational cost

## Epistemic state

`OBSERVED → DERIVED → INVARIANT → MODEL → FUNCTION → TERMINUS → DECISION`

No state is promoted merely because it is computationally efficient.

## Status vocabulary

`BUILT / SPECIFIED / PROTOTYPED / TESTED / VERIFIED / PLANNED / HYPOTHETICAL`

No `SPECIFIED → VERIFIED` shortcut.
